Manar Store 🌿

A natural products e-commerce website built with AI-assisted development.

About the Project

Manar Store is an e-commerce project designed to showcase natural hair, skin, and body care products.

Features

* Product categories for hair, skin, and body care
* Product listings and product details
* Shopping cart and order workflow
* Admin functionality for managing products and orders
* Responsive website structure

Technologies

* Node.js
* JavaScript
* HTML and CSS
* Database integration

Development

This project was developed with the assistance of AI tools.

Note

This repository is intended to showcase the project and its development. Deployment and production functionality may require additional configuration.
